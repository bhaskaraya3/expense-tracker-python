# Personal Expense Tracker

I'm building a simple command-line expense tracker to practise Python and improve my problem-solving skills independently.

The idea is simple: keep track of everyday expenses, see where the money goes, and understand spending habits instead of wondering where all the money disappeared.

I'm building it step by step rather than trying to implement everything at once.

## So far

- **Add Expenses:** Enter an item name and amount to record a new expense.
- **View Expenses:** Display all expenses currently stored in the application.
- **Delete Expenses:** Remove an expense by entering its item name.
- **Menu System:** Navigate between available operations using a simple command-line menu.
- **File Handling:** Check whether the file exists, create it if it doesn't, and store expense records in it.
- **File Updates:** Update the stored records whenever an expense is added or deleted.

## I'm using

- Python
- Lists and Dictionaries
- Functions
- Loops and Conditional Statements
- Basic File Handling (`pathlib`)

## Currently working on

I'm working on making expense records persistent so that they can be retrieved even after the program closes.
